# Odd and Even Checker

A simple Python program to check whether an entered number is even or odd.

## How It Works

The program asks the user to input an integer and uses the modulo operator (`% 2`) to determine if the number is:
**Even**: Divisible by 2 (remainder is 0)
**Odd**: Not divisible by 2 (remainder is 1)
